\# 📊 Loan Analysis Dashboard



\## 📌 Project Overview



This project focuses on analyzing loan application data to identify approval trends, borrower risk, and financial patterns. Interactive dashboards were built to support data-driven lending decisions and risk management.



\---



\## 🎯 Objectives



\* Analyze loan approval and rejection trends

\* Identify high-risk applicants using financial attributes

\* Understand borrower behavior and loan distribution

\* Support better decision-making in lending



\---



\## 🛠️ Tools \& Technologies



\* \*\*Power BI\*\* – Dashboard creation \& KPI visualization

\* \*\*Tableau\*\* – Interactive data visualization

\* \*\*Excel\*\* – Data cleaning \& preprocessing

\* \*\*SQL\*\* – Data extraction and transformation



\---



\## 📈 Key Metrics (KPIs)



\* Loan Approval Rate

\* Total Loan Applications

\* Loan Amount Distribution

\* Default Risk Analysis

\* Applicant Income Analysis



\---



\## 🔍 Key Insights



\* Identified patterns in loan approvals based on income and credit history

\* Highlighted high-risk applicants likely to default

\* Analyzed loan distribution across different categories and applicant profiles

\* Provided insights to improve loan approval strategies and reduce financial risk



\---



\## 📂 Project Files



\* `Loan Analysis Dashboard.xlsx` – Data preprocessing

\* `Loan Analysis.sql` – SQL queries

\* `Power Bi Dashboard.pbix` – Power BI dashboard

\* `Loan Analysis.twbx` – Tableau dashboard



\---



\## 🚀 How to Use



1\. Open Power BI file to explore interactive dashboard

2\. Use Tableau workbook for additional visual insights

3\. Refer SQL file for backend data queries

4\. Excel file contains cleaned dataset



\---



\## 💡 Conclusion



This project demonstrates how data analytics can improve financial decision-making by identifying risk factors and optimizing loan approval processes.
